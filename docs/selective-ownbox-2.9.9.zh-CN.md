# OwnBox 2.9.9 选择性跟进

作者：雾晚

> 范围说明：本文记录的是针对 OwnBox 2.9.9 的历史选择性适配，不是当前版本功能清单。以本文件核对基准（origin/main=f2886b9，2026-10-06）为准，仓库 NB4A 元数据标注正式版 3.0.6、预览版 3.0.7-preview.5；下文的基线、实现与测试说明仅描述当时这项适配，不代表当前版本逐项状态。

基线：wanBox origin/main 8067b157；OwnBox 1a27397d（2.9.8）到 0bdb0248（2.9.9）的一个净提交。共同祖先为 55f0e6878fe35c192c40101ef300ad3a448d0296。官方 alpha.10 为 c992297988288565a24a6d36e2cf4d77cb835fcd，是独立升级项，不算上游2.9.9新增。

| 内容 | 处理与依据 |
| --- | --- |
| 通知层次、移除累计流量 | 移植行为，首页/数据库累计计数不变 |
| 偏好即时生效、脏值缓存 | 自行适配，在同一锁内比较/发布/提交；发布失败不提交；包内广播刷新，不重启VPN |
| 活动成员 | 不复制上游猜测首节点和应用进程API读取；读取实际运行核心的选择器/测速选择或最近成功均衡成员 |
| Root 实时通知 | 复用原 watchdog 定时器及 stdout 管道；限长JSON仅含标签与计数，无新监听端口/HTTP轮询；关闭核心前等待watchdog退出 |
| 教程 | 补充中英文路由、应用分流、API、均衡、FakeIP、备份；保留现有搜索和页面 |
| 100%防泄漏、高可用、Google自动联动、放宽WebView | 不迁移，不符合wanBox能力或安全策略 |
| alpha.10 | 独立升级单一pin，DNS transport适配新增Scope生命周期参数；重建AAR和四ABI root二进制 |
| 上游品牌/版本/签名/其他UI | 不迁移 |

VPN从现有TrafficLooper采样后读CurrentOutboundTag。Root由独立运行核心采样，通过现有管道读取，仅接受当前process/proxy/ready/Connected会话。均衡可能同时使用多个节点：通知只表示最近成功使用的成员，不是唯一连接。未知成员显示等待，不沿用旧节点。停止清缓存，唤醒先清速率等待新样本。读取不触发拨号、测速或推进轮询。

新增观察器、缓存重复发布/失败重试/并发、Root采样校验、搜索测试。继续执行原有备份、路由、安全和配置测试。预览升级门禁验证正式3.0.5、预览3.0.5-preview.2覆盖安装，以及OwnBox并存、四ABI签名、递增版本、哈希。

真实Root手机的联网、通知外观、锁屏及OEM行为尚需人工验证；模拟器测试不等同于Root真机回归。
