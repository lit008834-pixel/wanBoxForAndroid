# 安全、数据与生命周期整改记录

作者：雾晚

对应用户提供的两份 v3.0 审计文档，基于仓库正式版 v3.0.3 实施。

## 已实施

| 问题 | 修复与验证入口 |
| --- | --- |
| 外部广播和快捷方式启停 | 私有 WidgetControlReceiver、快捷方式确认；独立测试 APK 验证 |
| 恢复中途失败破坏数据 | BackupRestore 全量解析，SQLite ATTACH 与 TRUNCATE 日志保证跨库事务；Android 仪器测试注入晚期错误 |
| 升级失败自动删除数据 | 补齐 1→2→3 迁移，取消破坏性回退；DatabaseRecoveryActivity 保留文件供诊断 |
| 页面任务和引用存活 | 备份、自定义图标、配置列表等使用视图生命周期；解绑 RecyclerView、工具栏与 TabLayoutMediator |
| 服务停止后的任务 | 先取消并等待流量任务、子进程，再关闭核心；禁止停止后重建流量任务 |
| 无界输入 | JSON 16 MiB、原始来源与 ZIP 解压总量 64 MiB、单 ZIP 条目 32 MiB、最多 128 条目；按实际读取字节计数 |
| 大图片解码 | 解码前读取尺寸，最长边不超过 2048 像素；旧系统采样解码，新系统目标尺寸解码 |
| 明文与面板认证 | 网络默认禁止明文，仅允许精确回环地址；Clash API 持久随机密钥，内置 YACD 同源配置 |
| 自动备份泄露 | 支持平台要求客户端加密；不支持时排除自动备份，保留手动导入导出 |
| 测速取消 | Kotlin 结构化协程同步取消 Go 请求上下文，退出前等待清理 |

## 验证方式

本机未配置 Java/Android SDK，`app:testOssDebugUnitTest` 无法在本机执行。使用 GitHub Actions 的完整单元测试、Go 测试、API 35 数据库与外部应用仪器测试，以及预览版签名、包名、升级共存检查。工作流的实际结果以对应运行记录为准，失败不计为通过。

## 保留与待验证

- 不删除原生库、Root 功能、协议、语言和资源；没有足够设备矩阵证明这些删减不会破坏功能。
- 暂不大范围收紧 R8 保留规则；保留收缩映射与包内容清单供后续按证据调整。
- 尚未验证 Root 真机、API 21–23、长时间切换的 PSS/RSS 峰值与 12/48/100 MP 真机扫码。图片尺寸单元测试不能代替真实二维码识别测试。
- 诊断 ZIP 是故障文件副本，不能当成已验证可恢复的逻辑备份。恢复必须先保留原文件。
- 已知第三方 HTTPS 面板不能再跨源连接本地明文 API，请切换内置 YACD 或配置 HTTPS 后端。
- 超限输入会被拒绝；大订阅需要拆分。上限不等同于所有低内存设备绝不会发生内存不足。

SQLite 跨库事务依据：[ATTACH 文档](https://www.sqlite.org/lang_attach.html)，要求主数据库是文件且不使用 WAL。
